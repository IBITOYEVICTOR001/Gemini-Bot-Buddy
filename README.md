# Gemini-Bot-Buddy

An interactive AI chat application built with TypeScript and HTML, utilizing the Gemini API for smart, real-time responses.

## 🚀 Live Demo
Check out the live deployed application here: [Gemini Bot Buddy](https://onrender.com)
*(Note: As this is hosted on a free Render tier, the initial load may take up to 60 seconds to spin up the server).*

## 🛠️ Tech Stack
* **Language:** TypeScript
* **Frontend:** HTML5, CSS3 / Tailwind
* **Hosting:** Render

## ⚙️ Features
* Real-time conversational AI interface
* Responsive web design for mobile and desktop views
* Secure integration with API endpoints
